# MeetingsBookingService
The service for booking single or recurring appointments (including infinite recurrence) for a resource.

Design and implement APIs for booking single or recurring appointments (including infinite
recurrence) for a resource. The system should:
● Check availability based on existing meetings (single & recurring).
● Avoid double-bookings.
● Provide next available slot recommendations when conflicts occur.
● Be performant under load, with evidence from load and spike testing.
